# r101 Test Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a launcher button "Test r101 randomizer" that writes a fixed, verified enemy-list
sidecar for the village square: castle zealots, Garradors and Verdugos, **with sound banks enabled**.

**Source of truth:** master's docs (`enemy-types-user-guide.md`, `enemy-type-randomizer-research.md`,
`pc-randomizer-decompile-findings.md`) + the r100 findings doc on this branch.

**Architecture:** same offline sidecar path as r100; no native change. Only `etc/emleon00.esl`
records with room `0x0101` change. `EnemyShuffle.dealR101Test` handles the fixed deal; a full-width
button in `MainActivity.randomizerSection` runs it off the UI thread.

## Decisions locked in

- All 46 r101 enemy records (43 Ganados, 1 cow, 2 chickens) become castle enemies.
- Zealots and Garradors share **one module**, id `0x1B`; Garrador = type 10, zealots = type 7/8.
  This is what makes the sound budget fit without skipping banks.
- Verdugos are id `0x2C` (em2c), on two **dormant** rows (n=11, n=37) so the bell's initial
  Ganado count is unchanged. `SceCountEmAlive(0x10,0x20)` does not count id 0x2C.
- Garrador rows n = 3, 12, 19, 27, 35, 43; all other rows are zealots (38).
- Weapon bits are cleared; HP normalised to 1200; room/pos/rot/Character/Guard_r/be_flag kept.
- `set` is reset to 0: r101's set values name bucket/cart/Suki motions that exist only in em15's
  event data. The castle module has no such motions and crashed in `MotionSetCore` on entry.
- Exactly four module kinds in the room: `0x15` and `0x26` are loaded by r101 itself for event
  data, plus `0x1B` and `0x2C`. The chickens' `0x28` module is deliberately eliminated.
- Sound banks stay on; the stale `r100-no-sound` marker is deleted by this test.
- Measured ARAM sound budget: em15 `0x1995e0` + em26 `0x1a800` + em1b `0x1f7ec0` +
  em2c `0x111d00` = `0x4bd9a0`, inside the `0x50bf00` space below music at `0x700000`.
